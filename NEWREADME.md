# RainyDays Portfolio 1 CA

Purpose of this project is to simulate a E-commerce/store through HTML and CSS, and now JS.

## Description

The website will allow the user simulate the experience of visiting a live store, with clickable buttons that lets the user browse mulitple products or one special product.

- Clickable navigation bar
- Products page, intended to show the user multiple products.
- Let the user simulate the action of adding product to cart and finish the purchase.
- Allow the user simulate sending feedback to the company.
